Personal CLI Assistant

Aplikasi command-line sederhana menggunakan Python untuk mengelola daftar tugas (to-do list). Dibangun untuk mempelajari konsep Function, File I/O, OOP, dan penggunaan Git dalam pengembangan proyek nyata.

Python OOP File I/O CLI Git
💻 Source Code 📄 Dokumentasi

OVERVIEW

Tentang Proyek

🎯 Tujuan

Proyek pembelajaran untuk memperdalam Python dengan membangun aplikasi nyata yang bisa dipakai sehari-hari: mengelola tugas pribadi lewat terminal.

👤 Peran Saya

Solo Developer — merancang struktur aplikasi, menulis kode Python, dan mengelola versi proyek menggunakan Git & GitHub.

⏱️ Durasi

± 3 minggu (November 2024), dikerjakan secara mandiri sebagai proyek latihan.

📦 Status

Selesai — versi 1.0 stabil, mendukung operasi CRUD tugas dan penyimpanan file JSON.

FITUR

Fitur Utama

  • ➕

    Tambah Tugas

    Menambahkan tugas baru dengan judul, deskripsi, dan prioritas (rendah/sedang/tinggi).

  • 📋

    Lihat Daftar Tugas

    Menampilkan semua tugas dalam format tabel rapi langsung di terminal.

  • ✅

    Tandai Selesai

    Menandai tugas sebagai selesai dan memisahkan dari daftar tugas aktif.

  • ✏️

    Edit Tugas

    Mengubah judul, deskripsi, atau prioritas tugas yang sudah ada.

  • 🗑️

    Hapus Tugas

    Menghapus tugas dengan konfirmasi untuk mencegah kesalahan.

  • 💾

    Penyimpanan Otomatis

    Data tersimpan ke file JSON lokal sehingga tetap ada saat aplikasi ditutup.

STRUKTUR

Arsitektur Kode

📦 Class Task

Model data tugas: id, title, description, priority, done, created_at.

📦 Class TaskManager

Mengelola list tugas: add(), list(), update(), delete(), complete().

📦 Class Storage

Menangani baca/tulis file JSON: save() dan load().

📄 main.py

Entry point: menampilkan menu CLI dan memanggil method dari TaskManager.

PROSES

Tantangan & Solusi

⚠️ Data hilang saat aplikasi crash

Solusi: Menyimpan otomatis setiap kali ada perubahan (add/update/delete) ke file JSON, bukan hanya saat keluar aplikasi.

⚠️ Kode awal terlalu panjang di satu file

Solusi: Memisahkan ke beberapa class (Task, TaskManager, Storage) agar lebih rapi dan mudah di-test.

⚠️ Input user tidak valid (mis. kosong)

Solusi: Menambahkan validasi input dan try-except pada setiap prompt agar aplikasi tidak crash.
